# План кваліфікаційної роботи

**Тема:** Вебсистема автоматизації бізнес-процесів та обслуговування клієнтів масажного центру (Calma).
Обсяг ≈ 60 сторінок. Розділи 1–2 — звіт з практики (квітень).

## Графік
| Етап | Що готово |
|---|---|
| Практика (4–6 тижнів, квітень) | Розділи 1 і 2 |
| Предзахист | Всі розділи + працюючий продукт |
| +2 тижні | Правки |
| Далі | Перевірка на плагіат |

## Розділ 1. Аналіз предметної області (≈15–18 с.)
1.1 Масажний центр як об'єкт автоматизації: послуги, майстри, клієнти, записи, оплата
1.2 Бізнес-процеси «як є» (запис по телефону, облік у зошиті) та проблеми
1.3 Огляд аналогів: Fresha, Booksy, YCLIENTS, Altegio — порівняльна таблиця (запис онлайн, ролі, аналітика, ціна, мобільна версія)
1.4 Постановка задачі, функціональні та нефункціональні вимоги
1.5 Вибір технологій: Next.js, TypeScript, Tailwind, Drizzle ORM, Better Auth, Clerk, FSD — обґрунтування
Висновки до розділу

## Розділ 2. Проєктування системи (≈20 с., без коду)
2.1 Архітектура: клієнт–сервер, Next.js App Router, шари FSD (діаграма шарів)
2.2 Ролі та сценарії використання (Use Case діаграма: клієнт, адміністратор)
2.3 Проєктування БД: ER-діаграма, опис таблиць, нормалізація (див. `DATABASE.md`)
2.4 Алгоритм пошуку вільних слотів (блок-схема, оцінка складності) — `slots.util.ts`
2.5 Алгоритм бронювання з повторною серверною перевіркою (діаграма послідовності)
2.6 Проєктування безпеки: автентифікація, ролі (RBAC), хешування паролів, захист серверних дій, валідація (zod), ізоляція даних користувачів
2.7 Проєктування UI: дизайн-система, світла/темна теми, адаптивність
Висновки до розділу

## Розділ 3. Програмна реалізація (≈20 с.)
3.1 Структура проєкту та налаштування середовища
3.2 Реалізація шару даних (схема Drizzle, seed)
3.3 Автентифікація: Better Auth + Clerk, сесії, `requireUser/requireAdmin`
3.4 Реалізація алгоритму слотів і бронювання (фрагменти коду)
3.5 Кабінет клієнта та панель адміністратора
3.6 UI: компоненти, теми, мобільна адаптація
3.7 **Тестування:** unit-тести алгоритму (`npm test`), ручне функціональне тестування, тест-кейси, перевірка безпеки (доступ без ролі, чужі записи, подвійне бронювання)
Висновки до розділу
